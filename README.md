# Auto Vids

**10-minute cartoon story videos, written, drawn and voiced by code on one PC.** Type one topic and a finished video comes out.

![Auto Vids in 15 seconds](media/demo.gif)

▶ [Watch the video (MP4)](media/brag.mp4)

**How it works**
1. **Story:** a plan and script written with Claude, each with its own story shape and tone
2. **Pictures:** every scene drawn locally in ComfyUI and checked automatically
3. **Voice and edit:** an expressive narrator, captions where the spoken word turns yellow, level maps, sound effects, and music that gets quieter under the voice

**Built with** Python · Claude · ComfyUI · Chatterbox TTS · FFmpeg
